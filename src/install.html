    2. Live TV channel lists (optional)

    Channel list URLs, one per line: a JSON file with a channels array, such as a site's embed manifest. Each channel shows up in Grayjay as its own channel with a live stream.

      3. Install

      On the phone that has Grayjay, tap Install. From another screen, show the QR code and scan it in Grayjay under Sources → +.
